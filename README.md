# TECTONICA

Русскоязычное издание об архитектуре и дизайне. Статический сайт на GitHub Pages, домен `tectonica.media`. Страницы содержат тексты и навигацию без JavaScript; JS нужен только для поиска и копирования ссылки.

## Редакция

Материалы и дата выпуска хранятся в `content.mjs`. Реестр кандидатов с результатами отбора — `editorial/`. Кредиты изображений находятся в материалах; адреса оригиналов — `assets/images/provenance.json`. Старый выпуск сохранён в `archive/legacy/`; старые якорные ссылки перенаправляются туда.

Для каждого выпуска сначала собрать 20–40 кандидатов из разных стран и рубрик. Проверить первоисточники, даты события и публикации, статус проекта и точность изображения. Не использовать другой проект как фотографию новости. Не превращать маркетинговые характеристики в проверенные факты. Публиковать достойные истории: 1–2 главные, 6–10 подробных материалов, короткая лента, продукты и выставки. Резерв сохранять с причинами. Не удалять прежние статьи при следующем выпуске.

## Сборка

Node.js 20+: `npm run build`, затем `npm test`. Внешние пакеты для сборки не нужны. Генератор обновляет статьи, рубрики, архив, поиск, RSS, метаданные и sitemap. Готовые HTML-файлы коммитятся в репозиторий и обслуживаются существующим GitHub Pages. CNAME не менять.

Перед публикацией проверить главную, статью, поиск и рубрику на мобильном и настольном экранах. Проверить изображения, ссылки и кредиты. Автоматическая ежедневная публикация без редакционной проверки не включена.

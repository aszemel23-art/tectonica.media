# Hoop Table Lamp: тема для рубрики света

Проверено 24 ноября 2026. Настольный светильник John Tree для финской марки Vaarnii соединяет основание из массива сосны с кольцевым абажуром из тонкого соснового шпона. Источники: [страница производителя](https://vaarnii.com/products/018-hoop-table-lamp) и [пресс-набор Dezeen Awards](https://www.v2com-newswire.com/en/newsroom/categories/competition/press-kits/4709-23/dezeen-awards-2026-design-project-of-the-year-winner-named).

Светильник не является новым изделием: [материал 2025 года](https://vaarnii.com/blogs/journal/one-thing-design) уже описывает его. Награду Dezeen Awards 2026 можно использовать как более поздний повод, указывая дату её объявления и не выдавая изделие за новинку.

Пресс-набор содержит три кадра именно Hoop Table Lamp, кредит Jussi Puikkonen; кадры других победителей к материалу не относятся. Нужно визуально просмотреть все три, подтвердить действующие условия использования, выбрать обложку, подписать остальные и проверить актуальный архив. Предварительный поиск по локальному архиву 24 ноября совпадений не показал.

Статус: перспективный обзор для рубрик света и дизайнеров, не готов к публикации. При сравнении для России отдельно проверить безопасность светильника, доступные материалы и производителя; не делать утверждений об экологическом преимуществе без данных.
